# Mini Browser 🌐

Mini Browser é um projeto de estudo desenvolvido em **Java** com **JavaFX**, com o objetivo de criar uma aplicação desktop simples para realizar pesquisas e acessar sites pela interface gráfica.

## 🛠️ Tecnologias

- Java
- JavaFX
- Maven

## 🎯 Objetivo

Projeto desenvolvido para praticar Java e explorar a criação de interfaces gráficas para aplicações desktop.
